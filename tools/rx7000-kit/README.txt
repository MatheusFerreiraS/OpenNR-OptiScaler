OpenNR RX 7000 test

This checks whether the new RX 7000 version of the mochizuki NR runtime works on your card.
It does not install anything and does not touch your games or drivers.

1. Unzip this folder anywhere (for example your Desktop). Keep about 500 MB free there.
2. Double-click run-test.bat. If Windows says it protected your PC, click "More info", then "Run anyway".
3. Wait. It takes about 10 to 30 minutes. It downloads the model files (about 250 MB) the first time,
   from the same place the OpenNR installer uses. The GPU fans may spin up while it runs; that is normal.
   Please close games and other heavy programs first.
4. When it says "Done", send us the file it names:
   OpenNR-RX7000-result-<date>.zip (next to run-test.bat, the folder opens by itself).

If the window closes or the PC freezes, restart, then send the "result" folder (zip it) and tell us
what happened.

You can delete the whole folder afterwards.
