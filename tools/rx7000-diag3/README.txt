OpenNR RX 7000 diagnostic kit 3

Thanks for running kits 1 and 2. They showed the mochizuki network giving a slightly different
picture every time on your card. This kit runs single pieces of that network (five of its steps,
each 50 times on the same fixed input) and checks whether each one gives the same answer every
time, and then tries changed versions of the suspect steps. It does not install anything and
does not touch your games or drivers. Nothing is downloaded and you don't need to copy anything
from the earlier kits: everything it needs is in this folder.

1. Unzip this folder anywhere (for example your Desktop). Keep about 200 MB free there.
2. Close games and other heavy programs.
3. Double-click run-test.bat. If Windows says it protected your PC, click "More info", then
   "Run anyway".
4. Wait. It takes about 5 to 10 minutes.
5. When it says "Done", send us the one file it names:
   OpenNR-RX7000-diag3-result-<date>.zip (next to run-test.bat; the folder opens by itself).

If the window closes or the PC freezes, restart, then zip the "result" folder, send it and tell us
what happened.

You can delete the whole folder afterwards.
