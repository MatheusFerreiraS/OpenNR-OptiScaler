OpenNR RX 7000 diagnostic kit 4

Thanks for running kits 1, 2 and 3. Kit 3 showed that each piece of the mochizuki network gives the
same, right answer on your card when it runs alone; the picture only goes wrong when the pieces run
one after another. This kit replays the network on your card piece by piece to find the first piece
that goes wrong in the sequence, tries several ways of separating the pieces, and then runs the whole
network with the best fix against the released 0.5.8 one on a test picture (4 sizes, 3 runs each).
It does not install anything and does not touch your games or drivers.

1. Unzip this folder anywhere (for example your Desktop). Keep about 1 GB free there.
2. Optional, saves a download: copy dlssnr-small.bin from kit 1's or kit 2's files\dlssnr-amd
   folder into this kit's files\dlssnr-amd folder. Without it the kit downloads it (about 110 MB)
   from the same place the OpenNR installer uses.
3. Close games and other heavy programs.
4. Double-click run-test.bat. If Windows says it protected your PC, click "More info", then
   "Run anyway".
5. Wait. It takes about 10 minutes.
6. When it says "Done", send us the one file it names:
   OpenNR-RX7000-diag4-result-<date>.zip (next to run-test.bat; the folder opens by itself).

If the window closes or the PC freezes, restart, then zip the "result" folder, send it and tell us
what happened.

You can delete the whole folder afterwards.
